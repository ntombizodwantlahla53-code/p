# Ntombizodwa Ntlahla: Portfolio Website

React + TypeScript + Vite. Styles are in `src/App.module.css` (CSS modules) and `src/index.css` (colour tokens and reset).

## Run it on your computer
```
npm install
npm run dev
```

## Put it on Vercel
1. Push this folder to a GitHub repository (replace the files in your portfolio repository if you want to keep the same Vercel link).
2. In Vercel, import the repository. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
3. Open your Vercel link and check that the new page shows.
